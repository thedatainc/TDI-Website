# thedatainc.com

Static site (HTML, CSS, vanilla JS). Hosted on AWS Amplify from the `main` branch; every push to `main` redeploys.

- Header and footer are injected by `main.js`.
- Contact form posts to Formspree (form mqpejgdl), delivered to atif@thedatainc.com.
- Old URLs (solutions-for-*.html, contact-us.html, privacy-policy.html, tos.html, meeting-schedule.html) redirect to the new pages.
